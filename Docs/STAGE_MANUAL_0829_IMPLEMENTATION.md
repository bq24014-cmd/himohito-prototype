# ステージ構成手順書 0829 実装対応表

この文書は`ステージ構成_手順書_0829.pptx`全41枚に基づく初期設計の対応記録です。以下の5区間チュートリアル、旧第8区間、消費44～45／終了5～6は当時の設計値として残しています。現行の配置・操作・残量は`README.md`と`Docs/METRICS.md`を優先してください。

2026-09-09確認：現行はチュートリアル4区間・開始99、本編は第8区間を除く9区間・開始50。検証済みの橋長の組み合わせでは、第6区間上ルートは合計51消費、第9区間で2補充されて終了1。下ルートは合計37消費・補充なしで終了13です。今回、ゲームの残量計算自体は変更していません。

## 全体仕様

- 構成：チュートリアル5区間＋本編10区間
- 本編開始残量：50
- 消費：接続・振り子・解除は0。`Q`で永久足場へ変えた時だけ選択長を消費
- 最低残量：1
- チェックポイント：残量が次区間の下限未満の場合だけ、下限まで補充
- 地形：最初から置かれた床、棚、壁、梁は振り子中も全方向から衝突
- 生成した足場：通常時は歩ける。接続中はプレイヤーとの衝突を切り、振り子軌道を妨げない
- 身体の見た目：残量に応じて4段階。50～35、35～20、20～7、7以下
- 基準値：地上速度6.5、最大射出14、ジャンプ高さ1.8・横幅3.2・滞空0.73秒

| 入力 | 操作 |
| --- | --- |
| `A` / `D` | 地上移動／振り子を加速 |
| `Space` | ジャンプ |

| 矢印キー | 照準 |

| `R` | 現在区間から再挑戦 |
| `Tab` | ヘルプ |
| `Esc` | ポーズ |

1. 想定した操作で3回連続成功する
