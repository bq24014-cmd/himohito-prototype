# 暖色ハサミ配置候補の起動

このタスクのローカル作業資料フォルダにある、次のファイルをダブルクリックしてください。

- 候補：`C05WarmScissorsPlacementProof_20261021/Manual/01_WARM_SCISSORS.cmd`
- 現行表示との比較：`C05WarmScissorsPlacementProof_20261021/Manual/02_PRODUCTION_REFERENCE.cmd`

1つずつ起動してください。どちらも同じ隔離Playerで本編第2区間の手前側から始まります。初期状態は位置(12.7, −4.28)、残量50、選択長7。候補だけ手前トゲが暖色ハサミへ変わります。

A/D移動・振り子、Spaceジャンプ、矢印照準、E接続／解除、W/S選択長、Q生成、F統合、R復帰、Tab操作説明、Escポーズなど既存操作を使用します。終了はウィンドウの×またはAlt+F4です。

手動版は最初の区間配置だけを行い、自動操作・自動接触・撮影・撮影時計・自動終了を開始しません。接触反応は既存ルールどおり、接続中の主人公が旧Triggerへ接触した際に起きます。刃の見た目と判定には不一致があるため、完成した危険判定として評価しないでください。

実行方式は既存非Development Player＋独立managed overlay＋外部の承認PNG。新規Unity Buildではありません。GitHubには画像・動画・資料のみを共有しており、Player一式を通常Gitへ追加していません。
