# C05 長さ比較の手動起動

Windowsのエクスプローラーで次を開いてください。`%USERPROFILE%`はご本人のユーザーフォルダです。

```text
%USERPROFILE%\.codex\visualizations\2026\08\08\019fdfa3-5ee1-7911-8a24-63282af5bae4\C05WarmScissorsLengthPassProof_20261021\Manual
```

- `01_Candidate.cmd`：今回の0.50倍修正版。
- `02_Previous.cmd`：前候補の1.00倍。原本は別フォルダに保持。
- `03_Current.cmd`：現行Productionのトゲ。Productionプロジェクトは起動・変更しません。

一つずつダブルクリックしてください。3つとも同じ隔離非Development Playerの候補切替で、本編第2区間の入口、残量50、選択長6から始まります。全ファイルをそのまま保ち、EXEだけを移動しないでください。

既存操作：A/D＝移動・振り子加速、未接続時W/S＝次の長さ変更、矢印＝照準、E＝接続・解除、R＝チェックポイント復帰、Tab＝操作方法、Esc＝ポーズ。長さ5／6／7は接続前にW/Sで選びます。終了はウィンドウの×またはAlt+F4です。対岸到達後はチェックポイントが進むため、入口から比較し直す場合はランチャーで再起動してください。

自動入力・撮影・自動終了・撮影時計は手動起動では有効になりません。修正版ランチャーの通常起動と35秒待機をログで確認しましたが、OS実キーによる攻略・Humanの今回の操作感は未確認です。

実行方式は既存Unity 6000.3.21f1非Development Player＋隔離managed overlayです。新規Unity Buildではありません。既存の腕レビュー用・A2・他のProofのランチャーは変更していません。

初期のPowerShell補助ランチャーはこの環境のスクリプト実行制限で起動できませんでした。最終の3つの`.cmd`はEXEを直接起動し、PowerShellやその設定変更を必要としません。権限・ファイアウォール設定は変更していません。
