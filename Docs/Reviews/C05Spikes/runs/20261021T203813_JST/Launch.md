# 上向き姿勢の比較起動

このタスクのローカル資料フォルダにある次のファイルを、1つずつ開いてください。

- 開いた静止姿勢：`C05WarmScissorsUprightProof_20261021/Manual/01_UPRIGHT_OPEN.cmd`
- 閉じた静止姿勢：`C05WarmScissorsUprightProof_20261021/Manual/02_UPRIGHT_CLOSED.cmd`

同じ隔離Playerで本編第2区間の手前側、位置(12.7, −4.28)、残量50、選択長7から表示します。終了はウィンドウの×またはAlt+F4です。

通常のゲーム入力は維持していますが、**ハサミは選択した開／閉の静止姿勢に固定**されます。今回は向きと接地の確認用で、接触で開閉する完成版ではありません。判定は旧トゲの矩形のままです。

手動ランチャーは自動入力・撮影・撮影時計・自動終了の引数を渡しません。今回の確認は静止撮影とコード上の起動経路までで、OSダブルクリック／実キー操作は未確認です。既存非Development Player＋managed overlay方式であり、新規Unity Buildではありません。
