# 手動比較の起動

Windowsの次のフォルダをエクスプローラーに貼り付けて開きます（%USERPROFILE% は本人のユーザーフォルダへ展開されます）。

```text
%USERPROFILE%\.codex\visualizations\2026\08\08\019fdfa3-5ee1-7911-8a24-63282af5bae4\C05ScissorsCutAudioProof_20261022\Manual
```

- **AFTER_SOUND.cmd**：今回の切断音あり。
- **BEFORE_SOUND.cmd**：同じ本体・配置・画角で、新しい切断音だけなし。既存BGM・効果音はそのまま。

一方ずつダブルクリックしてください。初期化に今回のPCで約20秒かかりました。本編第2区間の入口、選択長7・残量50で始まります。自動入力・撮影・自動終了・録音時計は有効になりません。

A/D移動・振り子、W/Sで未接続時の長さ変更、矢印照準、E接続／解除、R再挑戦。Escで既存ポーズ画面の効果音／BGM音量を調整できます。終了はウィンドウ右上の×またはAlt+F4です。通常のE解除や空白通過では、新しい切断音は鳴りません。

長さ7では刃に触れる経路を、長さ6では非接触の経路を比較できます。すべての操作タイミングで同じ結果になるという保証ではありません。ここで接触しても、地形・物理・長さ選択の調整は今回行いません。

実体はフォルダ内の `../Runtime/PlayerGroundingReview.exe` と付属データです。EXEだけ移動・改名しないでください。原音は `../Assets/HimoHitoScissorsSnip-v1.wav` です。音量を含めた確認にはゲーム内または[実Player動画](Video/After_PlayerMix.mp4)を使ってください。

既存非Development Player＋独立managed overlay＋WAVの実読み込みです。新しいUnity Buildではありません。手動起動・読み込み完了・待機・通常終了は確認済みですが、OSキーでの攻略とHuman実聴は未確認です。既存の固定レビュー環境・過去のランチャーは上書きしていません。
