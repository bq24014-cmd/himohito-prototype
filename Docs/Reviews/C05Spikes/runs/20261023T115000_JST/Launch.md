# 手動起動

Windowsの次のフォルダにある **Launch-Candidate.cmd** をダブルクリック：

`%USERPROFILE%\.codex\visualizations\2026\08\08\019fdfa3-5ee1-7911-8a24-63282af5bae4\C05RopeBladeContactProof_20261023`

比較元は同じフォルダの **Launch-Baseline.cmd**。元4deのRuntimeを使用し、原本を上書きしない。GitHubのLaunchersは起動ファイルの保存用であり、Build一式はGitに含めない。

本編S2入口、長さ6で開始。W/Sで5/6/7を選択し、既存の矢印照準・E接続／解除・A/D移動を使用。Rで復帰、Tabで操作説明、Escでポーズ。終了はウィンドウの×またはAlt+F4。

手動版は自動入力・自動撮影・自動終了なし、実時間。S2診断入口配置と対象ハサミの候補設定だけを起動時に適用する。既存非Development Player＋managed overlayで、新規Unity Buildではない。

候補の配置は下降0.45、比較元は下降0.95。候補のみ実ヒモ接触切断。音v4とほつれ演出は共通。
