比較したRoot位置、速度、残量、選択長、Camera、ハサミの開閉量、持ち手の接地差の最大差はすべて0。接続・接地・失敗・切断回数の状態列も一致しました。自然ルートの最終残量はいずれも50です。切断結果の一致だけでVisualの採用を判定していません。

自然落下失敗は切断から約0.14秒で起こり、物理が停止しますが、表示は約0.62秒まで完走します。旧接触毛羽は0、捕捉失敗0、Playerの記録エラー0です。After1600の全切断5件のうち、自然ルートは1件、残り4件は以下の独立したライフサイクル診断です。

- ほつれ進行中の約0.24秒で既存ポーズAPIを使用。8描画フレームの経過時間・全LineRenderer座標と透明度・進行量が不変。再開後も処理を継続。
- 同位置チェックポイントを使ったRで即時消去。移動量の検出に頼らず、既存の隔離R完了通知が効くことを確認。
- 入口への診断配置後、既存接地更新とTryAttachを同フレームで呼び出し、再接続専用の消去分岐を確認。本物のヒモと接続は残る。通常経路での実キー再接続の証明ではない。
- 物理停止後0.7秒以上の待機で完走。自然失敗とは別の補助確認。
- E相当の通常解除、未接続Q、開閉だけ、未接続での刃接触は追加の音・VFXなし。

## 残る制限と自己評価

**刃と実際の表示ヒモ端の1.393823 world差は未解決です。** 自然接触時、Playerは刃へ触れますが、表示ヒモと刃の交点はありません。保存した頭側の実ヒモ端からのみ演出しています。毛羽だけを刃へ移す、ヒモを刃まで伸ばす、架空の切断片を作る対応はしていません。今回、条件や切断位置の変更には着手していません。

実画面の自己評価では、以前の同時フェードと違い、端から上へ消失が進むことと、落下失敗後にヒモだけが残る余韻が読み取れます。細い繊維は控えめで、特に720pでは目立ちにくいままです。大きな閃光・揺れ・停止はありません。「毛糸がほどける」より「ヒモが短くなっていく」と読まれる余地が残り、完成映像の自然さはHuman判断へ残します。

画面の細い斜線は解除後の既存照準ガイドで、追加した切断片ではありません。ハサミ側の既存微動・閉じ動作も保持しています。
