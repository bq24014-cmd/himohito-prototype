# 第2区間カメラ候補の手動起動

Windowsのエクスプローラーのアドレス欄に次を貼り付けて開きます。

```text
%USERPROFILE%\.codex\visualizations\2026\08\08\019fdfa3-5ee1-7911-8a24-63282af5bae4\C05SectionTwoCameraProof_20261021\Manual
```

1. `01_After_CameraLower095.cmd` をダブルクリックすると候補です。
2. 比較元は `02_Before_CameraOriginal.cmd`。同時に2本起動せず、一方を終了してから起動してください。
3. 終了はウィンドウの×またはAlt+F4です。

両方とも第2区間の入口、残量50、選択長6、1.00倍・下降0.95の同じハサミで開始します。違いは区間内のカメラ高さだけです。候補は−0.95、比較元は0。1600×900、ズーム8.7です。既存のA/D、矢印照準、E、W/S、R、Tab、Escを使います。起動時の診断配置はありますが、その後の自動入力・接続・解除・撮影・終了はありません。

第2区間でRを押すと入口の低い画角へ戻ります。対岸のCP3へ到達した後は、Rでそのチェックポイントへ戻り、元の高さになります。メニューへ戻らなくても、終了してランチャーを再起動すれば第2区間入口から比較できます。

Player本体は同フォルダの1つ上の `Runtime/PlayerGroundingReview.exe` と付属Dataです。EXEやDataだけを移動・改名しないでください。既存ランチャー・旧Proofは上書きしていません。

実行方式は既存Unity 6000.3.21f1非Development Player＋今回コンパイルした独立managed overlay＋前回と同じ承認PNG読込です。新規Unity Build成功ではありません。両ランチャーの20秒待機・応答・通常終了は確認済み、OS実キーの反応と今回のHuman試遊は未確認です。
