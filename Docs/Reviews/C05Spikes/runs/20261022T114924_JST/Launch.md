# 手動起動

Windowsの配置先は、このタスクの作業フォルダ内の `C05CutVfxProof_20261022/Manual/` です。Codexの完了返信に、その環境の絶対パスへのリンクを記載します。この公開資料には個人名を含むローカルパスを載せません。

- `Play_Candidate_v4_CutVFX.cmd`：今回の候補。
- `Play_Comparison_v4_OldFluff.cmd`：同じ音v4＋旧接触毛羽。

一方を終了してから、もう一方をダブルクリックしてください。初回起動は20秒程度かかる場合があります。本編第2区間入口、残量50、選択長7から始まります。自動入力・自動接続・自動撮影・自動終了はありません。撮影用時計も手動版では使いません。

A/D：移動・振り子加速、W/S：未接続時の選択長、矢印：照準、E：接続／解除、Space：ジャンプ、Q：橋、F：統合、R：復帰、Tab：操作方法、Esc：ポーズ。効果音音量は既存のポーズ設定へ連動します。終了はAlt+F4またはウィンドウの閉じる。

既存非Development Player＋独立managed overlayです。新規Unity Buildではありません。実行ファイルと付属データの一式は既存環境で保持し、EXEだけの改名はしていません。音v4とハサミPNGはRuntime/ReviewAssetsから実際に読み込みます。

長さ5／6の通過、7の接触は固定の自動比較経路で確認した結果で、どの入力でも同じ結果になる保証ではありません。今回、OS実キー・Human操作感・VFXのHuman採用は未確認です。

旧音v1版・旧Proof・Production・既存ランチャーは保持しました。今回のランチャーは専用フォルダに新規作成しています。
