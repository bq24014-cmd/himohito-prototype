# C17 手動比較の起動

既存の腕・Q・Tab・他レビュー環境とは別のC17専用フォルダ。新規Unity Buildではなく、既存の非Development Playerに新規Compileしたmanaged DLLを分離配置している。Unity Editorは不要。

Windowsのエクスプローラーのアドレス欄に、次を貼り付ける。

```text
%USERPROFILE%\.codex\visualizations\2026\08\08\019fdfa3-5ee1-7911-8a24-63282af5bae4\C17S5HookProof_20261020\Manual
```

1. **01_CANDIDATE_S5.cmd** をダブルクリック：余分な木片を描かない候補。
2. 閉じてから **02_CURRENT_S5.cmd**：現在のProduction Source表示と比較。

両方とも1600×900のウィンドウ、S5左レールから開始する。残量45、選択長6、橋0。初回は約20秒前後の初期化待ちがあった。自動入力・自動撮影・固定撮影時計・自動終了は開始しない。起動時のS5開始地点／Checkpoint設定だけは隔離fixtureによる。

上段の青リングと固定板を比較する。必要なら既存の矢印照準・E接続、A/D移動／スイング、E解除、Q橋生成、R復帰を使う。選択長は未接続中のW/S。基本操作・成立条件は本体と同じ。現在地から上段青フックへ直接接続できるかは距離等の既存条件に従う。自動攻略はしない。

終了はウィンドウ右上の×またはAlt+F4。一方を終了してからもう一方を開く。両Runtimeは別DLLなので、比較元を上書きする切替はない。

起動準備完了ログと短時間の生存は確認済み。OS実キーでの接続・スイングや、Humanの操作感・採否は未確認。
