# 観測方法・限界

全共有画像・動画は最終Windows Build_r3内で、前回candidate3と今回candidate4を同じ条件で自動撮影したもの。既存入力field／API、表示前の入力ミラー、明示的なオフライン30fps。内部APIをOSキーやHuman試遊と呼ばない。自動撮影のための新たなRoot位置・速度の設定は行わない。元のA2入口fixture初期化は両者共通。

通常速度動画は保存フレームを30fpsで連結したゲーム内時間に等速の動画であり、リアルタイム実行FPS計測ではない。撮影と無操作起動検証のみ無音指定。通常ランチャーは既存音を保持するが実聴未確認。

JPEGは実Unity画面の表示用プレビュー。比較ラベルは画面外。補助cropは3倍と明記。画面への描き足し・生成補完・ゲーム内画像のAI改変は行っていない。原フレームはローカルに保持する。

ポーズ前の比較では同じframe indexを使用。APIポーズの時間は実時計なので、以後は同じphase内の観測・各自の復帰条件で確認する。実Escやメニューを試したことにはしない。

腕の長さはモデル座標で測定。足裏は元の不透明画素から得た登録点。ヒモは元の冠点／Hook巻き付け接点と描画LineRenderer端点を比較。GPU上のすべての毛羽画素を測ったわけではない。

起動観測は読取専用。35秒経過後に、その検証が起動したexeの完全一致パスを照合して外部から終了。ゲーム内に自動終了・自動キー入力を追加しない。

computer-useの軽量一覧取得は3回ともタイムアウト（待機後の再試行、セッション再初期化を含む）。継続許可はあるが操作環境の応答は別問題で、OS画面・OSキーの確認は未成立。今回の許可を[作業メモ](OperationPermission.md)へ残した。新たな同じ承認を要求していない。

Humanの実キー・手応え・面白さ・Visual採否、全区間、全残量、F統合の再実行は未確認。実行モデル・思考量metadataの実測も未確認。Technicalのチェック数を品質の採用根拠にはしない。
