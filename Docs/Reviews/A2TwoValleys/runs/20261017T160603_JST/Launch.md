# 手動で遊ぶ方法 — 新しい隔離Build

Windowsの新規フォルダ（`%USERPROFILE%`を自分のユーザーフォルダに展開）：

```text
%USERPROFILE%\.codex\visualizations\2026\08\08\019fdfa3-5ee1-7911-8a24-63282af5bae4\PlayerBodyPumpProof_20261017
```

1. `START_BodyPump.cmd`をダブルクリックすると今回の候補を起動する。
2. 比較するときはいったん閉じ、`COMPARE_KnitArmsBaseline.cmd`をダブルクリックする。同じ`Build_r2/BodyPumpProof.exe`で、基準の編み腕表示（candidate4）へ切り替わる。古い糸状腕ではない。
3. 終了はウィンドウの×またはAlt+F4。OSによるこの終了操作自体は今回未確認。検証時は自分が起動したプロセスのパスを検証して外部終了した。

Unity付属DataフォルダやDLLを含むBuild一式をそのまま残し、exeだけを移動・改名しない。GitHubにはBuild一式をアップロードしていない。

通常ランチャーは1600×900・ウィンドウ、既存音あり。起動時に撮影・自動攻略・自動終了は始まらない。録画資料だけは1280×720・無音・明示的自動撮影。手動版の既定も今回の候補で、exe直接起動でも手動モードとなる。既存の固定レビュー環境・Q・Tabランチャーは別物で保持。

既存操作を使う：A/D移動・振り子入力、矢印キー照準、E接続／解除、Space未接続ジャンプ、W/S未接続時の次の長さ、Q橋、F既存統合、R入口復帰、Tab操作説明、Escポーズ。入力体系の変更なし。今回の目的は動作表現の比較で、A2地形の採用判断や攻略再試験ではない。

入口は残量24／選択長6／橋0。Rは既存A2の入口へ戻る。任意に「接続して入力を離す→A/D→逆入力→E解除→着地」、途中でEsc／再開を見比べてほしい。今回のHuman実操作結果はまだない。

ランチャーは自分の`Sessions/`配下に新規ログを作る。OSツールの利用可否は[操作許可メモ](OperationPermission.md)参照。音の実聴と実キーの応答は未確認。
