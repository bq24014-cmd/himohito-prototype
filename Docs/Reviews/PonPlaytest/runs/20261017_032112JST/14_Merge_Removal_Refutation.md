# 削除・統合候補の反証｜S1・S7・S10

**A=0、親レビュー済み・保存準備中（remote照合前）。** 10/6固定ソース/保存Sceneを読む非操作レビュー。実プレイ・改変・経路生成・新ステージ制作なし。01の候補表を再要約せず、削減案が壊し得る入口/解放/保存/終点の条件だけを点検した。

## S1｜共通の導入はKEEP、再確認の圧縮だけを比較

**弱い前提への反証B**：MainはTutorialクリア必須ではなく、選択長7・残量50で独立初期化される。Tutorialの最初の到達は接続中でも受理できるが、MainのCPは接続中を拒否する。「同じ練習を済ませ、同じ状態を持ち込む」とは言えない。保存SceneのS1着地床にはCP2/下限50がある。Editor再生成値を実体の代用にしていない。

- **残す最小単位**：Mainの開始床と、S2の精密な長さ課題の前に接続→踏み出し→解除を試せる機会。S2手前の復帰境界か、通常試遊で同等と確認した境界。
- **削減候補の操作**：Tutorial済みで既に説明できる単フックの再確認1回を、S2への助走と兼ねられるかという限定比較。共通S1全削除の推奨にはしない。
- **判断を覆す試遊結果C**：Main直入群で解除/CP受理/長さ修正を説明できなくなるなら短縮を撤回。直入/既習の双方で理解を保ち、独立した最初の振り子が反復だけならMERGE比較を支持する。今回、群別試遊も所要時間も無い。

反対側の限界：MainのCPコードは番号の連続順を必須にせず、より高い番号へ進める。CP2が無いだけでソフトウェア上必ず進行不能、とも断定しない。

## S7｜着地床/CP9を含めた一括削除は対象外

**新たに結んだ依存B**：保存SceneのCP9設定はS07着地床に1件あり、Setupも9/下限23に設定する。MainのF解放条件は区間9以上。CP9を失い、他の高いCPも未受理なら、S9の意図したF統合が解放されない。橋→振り子という見た目の共通点だけで、その着地床まで同じ重複物として削れない。

- **残す最小単位**：S6からS9へ通れる接続、Fを解放する区間受理、資源/橋/除去フックを保存するCP9相当の境界。中段→上段を使う判断は、重複と確認するまでは残す。
- **削減候補の操作**：既存10の同じ床内での復帰位置比較を先にする。後半失敗のたびに既習の橋準備/接近を繰り返す場合の圧縮候補であり、初回の高さ接続やCP9の削除ではない。
- **判断を覆す試遊結果C**：上段から狙う位置が意味ある判断/修正を生むならKEEPを強める。S4の再生だけで、短縮後もF解放・入口状態・資源差を保てた場合に限ってMERGEを再検討。現時点はREWORKを維持し、REMOVEへ上げない。

**資源反証の机上比較**：既存07のS6合流25/39、CP9下限23、S9支出12、CP10下限11、最後支出10を固定。参考S7支出4を消すだけでも、最後の計算値は1/13→3/17、差12→14になる。支出が無いから全て同じ、ではない。これは条件付き算術であり、実際に4以外で渡れるか、短縮案が通れるかの証拠ではない。

## S10｜REMOVE表記を外し、締めの限定MERGE候補へ狭める

**保存境界への反証B**：CP10はS9出口床にあり、下限11とその時点の橋/除去フックを保存する。参考経路でS9を統合して通過した場合、その成功を最後の橋の失敗から保護する。統合案でCP10まで消し、代替CPを受理しないなら、RはS9前の保存状態へ戻り、2回の橋作成とFを繰り返す条件が生まれる。章表示を減らすことと復帰境界の削除を混ぜない。

**箱への到達への反証B**：保存SceneのMainGoalZoneはS10終点床に1件。箱markerがあれば、床上接触だけでなく接近/開き完了を読む。判定時に箱markerが見付からなければ、marker-nullの旧形式分岐は床接触でtrueを返し得るので、「クリアは動く」だけでは箱への到達を守れない。終点床のreceiver機能まで取り除き、再生成もさせない案なら、その判定自体を失う。Setupには床/箱をEnsureする経路もあり、Sceneから消すだけでこの不在条件を作れるとは確認していない。いずれも削除を実行した結果ではない。

- **残す最小単位**：S9成功を保護するCP10相当、到達可能な最後の横断、箱へ近づき開く→クリアの関係と終点判定。最後に身体を道へ残すQも、削除損失を試遊比較するまでは保持する。
- **削減候補の操作**：独立課題としての再準備を締めへまとめる仮説まで。**現時点で安全に消せる必須キー操作は特定できない。** 通常S10の長い攻略文は未描画なので、「説明待ちを削る」案も捏造しない。
- **判断を覆す試遊結果C**：最後の長さ/消費選択や箱の反応を、自分の行動の結果として説明できるならKEEPを強める。再準備に新判断が無く、短い締めでもCP10・箱接近・身体/道/残量の意味が残る比較結果が出れば、限定MERGEを支持する。今夜の証拠からQ/箱/CP10削除を承認しない。

最後のQを行わず支出10を省く机上計算なら、残量は11/23。ただしQ無しで同じ谷を越えて箱へ届くことを証明していない。実際にその橋が無い状態でClearへ進めた場合、Snapshotはその時点の橋と残量を読むため、最後の橋は地図に含まれない。費用0だけから橋形状の変化を推定していない。既存06の端点差/箱への距離/時間定数を、実歩行時間として再利用しない。

**推奨差分**：S1は共通導入KEEP、S7は接続/CP9保持のREWORK、S10は全体REMOVEを外した限定MERGE比較。既存01の広いS10表記はこの狭い範囲で読み替える。上位5案の順と朝の1件は変えず、S10案の削減範囲を制約する。実試遊でしか解けない前提は未確認として止め、同じコードを読み直して面白さの確証へ替えない。
