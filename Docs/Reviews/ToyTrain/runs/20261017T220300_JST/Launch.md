# 手動起動

新規隔離フォルダ：

```text
%USERPROFILE%\.codex\visualizations\2026\08\08\019fdfa3-5ee1-7911-8a24-63282af5bae4\ToyTrainProof_20261017
```

`START_ToyTrain.cmd`をダブルクリック。Buildは`Build/ToyTrainProof.exe`。Data／DLL等も一式保持し、exeだけを移動・改名しない。既存ランチャーは上書きしていない。

1. A/Dで右へ歩いて汽車の明るい上面に乗る。最初は4秒停車する。
2. A/Dを離しても運ばれる。車上を歩くこともできる。
3. 青Hookが長さ7の範囲に入ったら、既存の矢印照準またはマウスで狙ってE接続する。初回接続は接地中。
4. Dで車から踏み出し、既存のA/Dで振り子へ。自分でE解除し、右の広い着地先へ向かう。
5. Rで乗り場と汽車を初期状態へ戻す。残量24／選択長7／橋0。落下演出中のR受付などは既存条件のまま。

汽車が先に出た場合は折り返しを待つかRで戻せる。Space、W/S、Tab、Esc等は既存操作。新しいキー・入力モードはない。

通常版に自動攻略・撮影・終了処理はない。画面は1600×900、実時間。終了は×またはAlt+F4を想定するが、今回OS操作は未確認。音も実聴していない。

既存の腕・A2・R・Q・Tab・固定レビュー環境は別のまま。新しいログはこのフォルダのSessions配下に作る。初見の楽しさ・Human採用はまだ確認していない。
