# C08 橋端の接地表示 Production統合

Human承認元は `9d7164b09dad656db9c60adbb0d452e38c17876f`。開始mainは `2a0a2b5f5d5478f5ee2c6be5553121683757ebf7`。C22・C23を維持し、橋で実際に支持されている間だけ、その局所橋面に合わせて人形の描画を補正する。物理位置、接地判定、橋の形、消費量は変更しない。

## 統合範囲

- `Assets/Scripts/RopeBodyVisual.cs`：支持橋の曲線差・しなりを読み、描画側だけを補正。岸で解除、離床後は短い表示遷移。接続ポーズへの受け渡しとR初期化を含む。
- `Assets/Scripts/RopeController.cs`：補正後の表示位置から同じ接続可能フックを通る照準ガイドを描く。実際の物理探索・到達距離・入力は従来のまま。
- 比較切替、fixture、診断UI、撮影、自動入力、終了処理は持ち込んでいない。新規Assetなし、既存meta不変。

## 回帰確認

承認済み隔離版の7群（水平T3、統合T4、Main S4、3サイズ・左右、歩行/停止/待機/岸往復、Q/F、接続/解除、ジャンプ、R、ポーズ）を再利用した。全結果のハッシュと件数は [Verification.json](Evidence/Verification.json) に記録。

比較分岐を除去した統合用ソースはUnity付属RoslynでCompile成功（エラー0、既存CS0649警告4）。その2ファイルとProductionのバイト一致を確認し、実Player内でT4の梁下・S4急坂を通常/中間/最小の3サイズで追加検証した。表示ガイドが指す緑フックへネイティブ接続成功6件。ガイドとフックの横ずれは最大0.000001未満world unit。ジャンプの離床と既存梁への頭上接触を記録。T4は修正前後291フレームで位置・速度・Camera差0、接触時の描画頭頂も同じだった。新たな重大不整合は今回の範囲では再現しなかった。

実行は既存非Development Playerへのmanaged overlayであり、新規Unity Build成功・Unity Editor Play成功・OS実キー成功と扱わない。OSウィンドウ取得はタイムアウトした。

## 残る制限

最小の人形より物理箱が大きい既存仕様は残る。T4梁下の頭上接触時、物理上端0.785に対して描画頭頂0.582（差0.203world）。これは修正前と一致し、C08による新規回帰ではない。全ステージの全照準角・全頭上障害物を網羅した保証ではない。急坂での反対側の足上げも保持し、両足固定はしない。

既存MainStage Scene・README・学習ログ・QAログ5差分、その他Runtime Source、Tutorial Sceneのハッシュを保持。この統合にC20の橋形状変更は含まれない。
