# Tutorial 第1区間 — 2.5D背景素材試作

作成日: 2026-10-01。**画像素材と静止プレビューのみ。Unity未導入。Gameplay変更なし。**

現在のヒモヒトの夜の子供部屋を参照し、窓外・部屋・手前のおもちゃを独立した3枚のPNGへ分けた試作。
毛糸、フェルトの縫い目、ピンク系カーテン、紺・紫の壁、暖色の木材という既存の方向性を維持する。
3Dモデルへの置き換えではなく、平面画像を奥行き別に配置するための2.5D案。

3層PNGとCompositeは **1920×1080**、共通キャンバス・原点。PNG色空間はsRGB。
生成元は1672×941。比率を維持したcontain拡大で1920×1080へ統一したもので、ネイティブ1920生成とは表現しない。
Near / Midには実際のalphaがあり、白マットを抜く処理や描き込まれた市松模様は使わない。
生成されたalphaを保持しており、Midの壁・木材も完全な255ではなく概ね251〜253のほぼ不透明値。
Farは不透明なので通常の合成では穴にならない。中央の壁は暗く保ち、Nearの中央は空けてある。

## 各層と見た目の狙い

- **Far:** 室内と切り離した月・雲・木の遠景。窓枠の内側から見える最も奥の面。
- **Mid:** 既存の子供部屋を認識させる主要面。窓のくぼみ、木の小口、吊り下がる布、棚下の陰を少し強める。
- **Near:** 汽車・毛糸玉・積み木の立体的な側面と局所的な接地陰。左右下側にまとめ、中央の遊び場を塞がない。

現行も`HimoHitoCraftRoomBackground`でFar / Midの2枚を利用している。
今回はその実装を変更せず、「夜景を含む壁1枚」から夜景と室内を分離し、既存の小物層から手前小物を独立させる別素材案を用意した。
静止画の立体感とレイヤー分離は確認済みだが、実際のパララックス効果・プレイ中の見え方は未検証。

## 想定するパララックス方向（未実装）

右へカメラが進むと、画面上の背景は左へ相対移動する想定。左へ進むと逆方向。
画面上での移動量は **Far < Mid < Near < Gameplay** とし、カメラ自体を揺らさない。

初回の検討値: `画面上の背景変位 = -係数 × カメラ移動量`。
同じ座標系でFar 0.02、Mid 0.06、Near 0.12程度から小さく試す。これは仕様変更ではなく将来の検討値。
上下追従・ズーム・揺れは今回は提案に含めない。

## Unityに組み込む場合の想定（今回未実施）

1. 採用判断後、専用Artフォルダへ3枚とUnity生成のmetaをセットで導入する。今回はDocsにのみ保存。
2. Sprite / sRGB / alpha有効、同一PPU・中央Pivot・Full Rectで3枚の位置を合わせる。透過余白を切り詰めない。
3. 描画順はFar→Mid→Near→既存Gameplay。Nearという名称でも、プレイヤー・Hook・橋・足場の前には描かない。
4. 背景専用ルートにだけ配置し、Collider・Rigidbody・入力・Gameplay Transformには接続しない。
5. 元背景と新背景の重複表示を避ける。今回のFarには室内の窓枠・壁がないためMidとセットで使う。
6. 画面端は壁・床が自然に続く構図、手前小物は切れない余白を確保。**無限タイル対応素材ではない。** 実装時は第1区間のカメラ可動範囲に合わせたoverscan、拡張画像または移動範囲制限を別途検証する。
7. 異なる画面比率、窓と月の位置、Hook周辺の視認性、足場との見た目の競合、酔いにくい小さな変位を実機で確認する。

窓枠で月が部分的に隠れるのは、窓外が独立した奥面であるため。プレビューは位置関係の初期案であり、運用Sceneへの採用を確定したものではない。
Before / Afterは同一Cameraによる変更前後テストではなく、背景案の比較。今回のlive Unity screenshotは取得していない。

## 保護・Git

Production `Assets/`、`Packages/`、`ProjectSettings/`の開始時462ファイルをSHA256で保護し、終了時に照合する。
開始時から存在する`MainStage.unity`の未Commit変更もそのまま保持。Scene Syncを実行するためのUnity起動は行わない。
新規出力はこのDocsフォルダ、検証補助はGit除外のtask一時フォルダのみ。
Source / Scene / Hook / 足場 / Collider / Physics / Cameraの変更、stage / commit / pushは行わない。
