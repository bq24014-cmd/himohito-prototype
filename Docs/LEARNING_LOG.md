1. どの入力を受け取ったか
2. どの値が変わったか
3. その値を誰が使うか
4. Unityの物理処理は `Update` と `FixedUpdate` のどちらで行われたか
5. 元に戻すにはどのコミットまで戻ればよいか

## 最初の実験

- `PlayerMover.moveSpeed` を `7` から `9` にする
- `Rigidbody2D.gravityScale` を `2.8` から `3.5` にする
- `RopeResource.maximumLength` を `20` から `12` にする

一度に全部変えず、1項目ずつPlayして、違いを1行で記録します。
