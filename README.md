# ヒモヒト — Unity 2Dアクションパズル

![ヒモヒトのキービジュアル](Docs/Images/HimoHitoKeyVisual-v1.png)

自分の身体であるヒモを伸ばし、振り子で飛び、必要な場所ではそのヒモを足場として残して進む2Dアクションパズルです。

舞台は、子供が眠った後の夜の子供部屋です。ほどけかけたあみぐるみが、積み木、玩具レール、棚、懐中電灯などを越え、おもちゃ箱を目指します。

## この試作で確かめること

- 自分の身体を使って振り子で飛ぶ動きに爽快感があるか
- 次に使うヒモの長さを選ぶことで、移動前に考える時間が生まれるか
- ヒモを永久に足場へ変える判断が、残量を配分するパズルとして機能するか
- チュートリアル4区間と本編10区間の設計を通して、教える・試す・ひねるの順番が伝わるか

## 基本ルール

ステージ選択の島は小さなジオラマになっています。練習の島を選ぶとヒモヒトがヒモ橋を往復し、本編を選ぶと宝箱が約0.8秒で開いて暖かく光ります。選択を外すと主人公は休み、宝箱は約0.5秒で閉じます。説明中は停止し、島やカメラは動かしません。専用素材と仕組みは [STAGE_SELECTION_DIORAMAS.md](Docs/STAGE_SELECTION_DIORAMAS.md) を参照してください。

旧タイトル画面を外し、起動直後から、布の地図に置いた小さなおもちゃの島を毛糸でつなぐステージ選択画面を表示します。専用の背景・練習場・宝箱の島・布ラベルを制作し、←→／A・Dまたはクリックで選び、Enter／「ここであそぶ」で開始します。ゲーム名・操作説明・ゲーム終了もこの画面へ統合。チュートリアルと本編はどちらも第1区間から選択可能。今後は `Assets/Resources/StageCatalog.json` へ登録することでページを増やし、専用の島イラストも指定できます。追加手順は [STAGE_SELECTION.md](Docs/STAGE_SELECTION.md)、画像と生成プロンプトは [STAGE_SELECTION_ART.md](Docs/STAGE_SELECTION_ART.md) を参照してください。

ヒモ橋の上から次の橋をQで生成した場合は、現在立っている橋とプレイヤー位置を維持します。2本の長さが異なっても中央フックへ瞬間移動しません。1本目を生成するときの端への配置、選択長に応じたたわみ・消費、Fで2本の長さを合算する処理は従来どおりです。

ステージ選択には、遊べる2つの島の右に「つぎの冒険／追加予定」を表示します。布をかぶせた島と途切れた毛糸の道で予告を表現し、選ぶと「新しいステージを追加予定」と案内します。開始はできず、クリアによる解放条件や公開日は設定していません。予告枠にシーンは割り当てず、ビルド対象も既存2シーンのままです。

クリアした島には、ピンクの毛糸旗と「CLEAR」の布タグが付きます。本編・チュートリアルの結果が確定した時点でステージIDごとに端末へ保存し、再起動後も表示します。未クリアのステージも自由に選べ、追加予定の島は従来どおり開始できません。導入前の履歴はなく、今回以降のクリアから記録します。途中の区間や橋のセーブは追加しません。

島を選ぶと、その周囲にピンクの毛糸が0.32秒で一周し、最後の0.08秒で小さな結び目ができます。別の島へ切り替えたときだけ編み直し、同じ島の再クリックや放置では繰り返しません。操作説明中は止まり、閉じると続きから再開します。島・カメラ・音は変えず、演出完了を待たずに開始できます。

Enter／「ここであそぶ」で開始すると、選んだ島から毛糸が約0.22秒で右へ伸び、紺色の布を約0.58秒で左から引き込みます。画面を完全に覆ってからステージを準備し、既存の紹介カメラがゴール側で待機した状態を約0.62秒で左から見せます。布が開き終わってから通常のカメラ紹介が進みます。途中の連打・選択変更・操作説明・Escは受け付けず、追加予定の島では演出を始めません。新しい音・物理変更・配置変更・保存項目は加えません。仕様と布の生成記録は [STAGE_START_CURTAIN.md](Docs/STAGE_START_CURTAIN.md) を参照してください。

プレイ中はEscのポーズ画面から「ステージ選択へ」をクリック、またはT→Enterでステージ選択へ戻れます。確認画面のEscはキャンセルで、現在のゲームを維持します。戻ると区間・ヒモ橋の進行をリセットし、選んだステージの第1区間から新規開始します。音量設定は保持します。選択画面のTab／「操作説明」で説明、Esc／「ゲーム終了」で終了します。各ボタンはクリックにも対応。説明中は背後の選択・開始・終了を無効にし、Tab／Esc／「閉じる」で説明を閉じたフレームも入力を消費して誤終了を防ぎます。Unity Editorの終了操作はPlayモード停止、配布版ではアプリ終了になります。

本編第3区間の帰り道スイッチのすぐ横で立ち止まってFを押すと、主人公がスイッチ側へ向き、膝を曲げ、手で押して起き上がる専用6コマを約0.5秒で再生します。歩行・ジャンプ・落下・ヒモ接続・再挑戦では即座に中断し、ポーズ中は止まります。離れた位置や空中でのFは従来のスイッチ動作だけを維持し、主人公を引き寄せません。足場の有効化はFの瞬間のまま、移動・コライダー・残量・音は変更しません。画像と生成プロンプトは[SWITCH_PRESS_ART.md](Docs/SWITCH_PRESS_ART.md)に記録しています。

接続中のフックの結び目は、張ったヒモで速く振り子になるほど横幅が最大28％締まり、引く方向へ少し伸びます。ヒモがたるむ／接地すると滑らかに緩み、絵の向きだけが主人公へ追従します。距離・接線速度・重力から求める表示用の荷重であり、物理の張力は操作しません。ヒモ橋の両端の巻き付けは、橋を支えているプレイヤーに近い側ほど細く締まり、橋側へ少し引かれます。離れると自然に戻り、一定周期で勝手に脈動しません。接続直後の結び上がり、Eで戻るヒモ、Q生成、Fでほどける動きを維持し、Fでは直前の締まり具合を引き継ぎます。両ステージ共通、ポーズ中は停止。フック位置・橋・コライダー・速度・資源・音・光・カメラは変更しません。

チュートリアル第3区間のヒモ橋は長さ7を推奨します。看板の手順と動く説明も推奨7・消費7で案内します。最低必要距離6の生成判定は維持し、選択長を自動変更しません。第4区間の2本をまとめる課題は従来どおり各6です。

地上で壁へA／Dを押し続けると、主人公が手を伸ばして両手で壁を押し、膝を曲げて踏ん張ります。専用の6コマ素材から手を伸ばす2コマ、押している3コマを再生し、キーを離すと約0.12秒で通常の姿勢へ戻ります。逆方向の移動・ジャンプ・空中・ヒモ接続・再挑戦では即座に解除。フックやトリガー、生成したヒモ橋には反応せず、ポーズ中は停止します。小さくなった主人公も絵だけを補正して手を壁へ合わせます。本編・チュートリアル共通で、物理・残量・移動・音・カメラは変更しません。

E（補助マウス操作も共通）で掛け損ねると、頭から照準方向へ短い毛糸が0.13秒で伸び、先端が柔らかく垂れて、合計0.56秒で頭へ戻ります。通常ヒモと同じ透過の撚り模様を使い、照準線は維持。成功した接続・再挑戦・失敗では即座に片付け、連打しても増殖しません。ポーズ中は停止します。接続判定・移動・残量・既存の射出／空振り音は変更せず、光・フラッシュ・カメラ揺れもありません。

本編・チュートリアルで、接続中の主人公がトゲに触れてヒモが外れると、接触点から既存の毛糸素材の短い繊維が4本散り、約0.4〜0.65秒で消えます。触れたトゲの絵だけが底を支点に小さく揺れ、0.4秒で元の姿勢へ戻ります。接触し続けたときの重複演出はなく、ヒモ未接続の接触では出ません。ポーズ中は停止し、無効化時は姿勢を復元します。解除・残量・速度・当たり判定は従来どおりで、主人公を跳ね上げず、そのまま落下させます。追加の音・光・フラッシュ・カメラ揺れはありません。

本編第3区間の帰り道スイッチは、Fを押すとボタンが約0.24秒で沈み、近い足場からA→B→C→Dの順に約0.14秒ずつずれてせり上がります。木の絵を0.65ユニット下から短くフェードインし、最後にわずかに沈んで止まる約1秒の演出です。床本体と当たり判定は従来どおり押した瞬間に有効になり、位置・サイズ・ジャンプ力は変えません。手前の床へ戻る／再挑戦すると演出を片付けて隠れ、再び押せます。ポーズ中は停止し、音・光・カメラ揺れは追加しません。

帰り道スイッチの見た目は、柔らかいピンクの編み地と蜂蜜色の木台へ統一しています。台に巻いたヒモ・右側の結び目を残し、絵の幅・接地位置・Fの動作と押し込み演出は維持。新しい専用素材だけ縮小用mipmapを使い、旧素材もフォールバックとして保持します。素材と生成プロンプトは [CRAFT_RECOVERY_SWITCH_ART.md](Docs/CRAFT_RECOVERY_SWITCH_ART.md) を参照してください。

ヒモ橋の両端には、フックの縁へ毛糸を巻き付けた装飾が付きます。Qでは既存の0.3秒の編み上がりを待ってから約0.22秒で締まり、Fで2本をまとめると中央の2つだけが約0.4秒でほどけ、下がる橋へ追従して消えます。外側の巻き付けは残り、再挑戦で復元する橋は最初から締まった状態です。物理形状・歩行・ヒモ消費は変えず、ポーズ中は停止、追加の音や光はありません。

ステージ内の青い通常フック・緑の足場用フックは、毛糸を巻いた手芸用の輪と、背景・足場に合う蜂蜜色の木台へ質感を統一しています。専用の青・緑・木台素材を使い、既存のUIアトラスは変更しません。ピンクの固定用の結び目と垂れたヒモは維持し、台はリング上部の後ろに配置して中心の穴を隠しません。装飾には当たり判定がなく、接続点・リングの外径・青／緑の役割・照準表示・歩行は従来どおりです。リングを非表示にすると台も隠れ、既存の接続時の引かれる動きにも一緒に追従します。再生時と `HimoHito > Preview > Refresh Scene Visuals` で確認できます。素材と生成プロンプトは [CRAFT_HOOK_ART.md](Docs/CRAFT_HOOK_ART.md) を参照してください。

看板を開かなくても、ステージ上の木製看板の小さな絵が動きます。振り子、長さによる失敗／成功、橋の生成と歩行、2本から1本への変化を各区間で繰り返します。第4区間は橋がない状態から、左・右の順に編むところから開始。元の透過プレイヤーと毛糸模様を使用し、看板のお辞儀にも追従します。プレイ中だけ動き、ポーズ・説明画面では停止。編集画面では静止した代表図を表示します。Zで開く詳しい説明も引き続き使えます。

チュートリアルの看板をZで開くと、説明画面内のイラストが「操作→変化→結果」の順にゆっくり動きます。第1区間はE接続から振り子で対岸へ、第2区間は長さ8でトゲに当たる例から6～7で渡る例へ、第3区間はE→Qで編まれる橋と歩行、第4区間は左岸→中央へE・Qで1本目を作り、その橋を歩いて中央へ進み、右岸へE・Qで2本目を作ってから、Fで1本へ下げて梁をくぐる例です。第1〜3区間は約10〜13秒、第4区間は約21秒で繰り返し、操作前後は静止、繰り返しの切り替わりだけ短く薄くして位置の飛びを隠します。開き直すと最初から。既存の透過プレイヤー画像を縦横比維持で移動し、毛糸模様も維持します。ゲーム本体は引き続き停止し、説明図だけ非スケール時間で進みます。説明用の模式図であり、ステージ配置・物理・実際のヒモ残量・音・Zの操作は変えません。

木の床を歩くと、既存の足音のタイミングに合わせて足元から小さな毛糸の繊維が2本落ちます。着地の繊維より小さく、約0.28〜0.42秒で消え、床に軌跡を残しません。足元の最初の支持面が木製の場合だけ表示し、ヒモ橋・レール・空中・停止中・壁に押し付けたままでは出しません。ヒモ橋では既存の踏み締め演出を維持します。追加の音はなく、移動・衝突・残量・カメラは不変更。ポーズ中は停止します。

接続できるフックを狙うと、既存の輪郭強調に薄い暖色の光と接続点の小さな目印を重ね、照準線の表示方向がフックへ吸い付きます。線はフック位置で止めず、その方向へ選択した長さ分だけ描くため、W／Sで7→8などへ変えると線も1ユニット伸びます。フックの目印とは別表示です。青／緑リングそれぞれの絵の大きさに沿って約0.2秒で明るくなります。届かない場合は従来の破線リングと入力方向の照準線を維持。E接続・照準外・ポーズ・失敗／ゴールなどの操作停止で光と目印を消します。第6区間の空中再接続は、既存処理が選ぶ次のフックを示します。矢印キーの照準角・射程・接続判定・ジョイント・資源・音・カメラは変えません。

主人公は残量30％以下で少し不安そうな毛糸の眉、10％以下で眉を寄せた踏ん張る表情になります。本編50では残量15／5が目安。元の目・まばたき・各アニメーションはそのままに、目元だけを約0.35秒／段階で変えます。回復時は14％／34％を超えると順に戻るため、境界付近で表情がちらつきません。左右の向き・振り子の回転・照準で上を向く顔にも追従し、ゴール・失敗・編み戻り中は既存演出を優先します。チュートリアル99も同じ割合で判定。看板のプレイヤー画像は変えず、ポーズ中は停止し、資源・物理・操作・音は変更しません。

チュートリアルの4つの木製看板には、開く前から内容が分かる小さな絵と操作キーを表示します。第1区間はフックに掛けるヒモ＋E、第2区間は谷・トゲと安全／長すぎる振り子の軌道＋W／S、第3区間は緑フック間のヒモ橋＋Q、第4区間は2本を1本にまとめる絵＋F。全4区間に本編と同じ小さなプレイヤーを背景透過・縦横比維持で表示します。第2区間は、安全な軌道がトゲを越え、長すぎる軌道は当たることを破線とチェック／×でも示し、橋と混同させません。既存の毛糸素材とM PLUS Rounded 1cの太字を使い、看板の絵の子として一緒にお辞儀します。看板サイズ・位置・Zの読む範囲・開いた説明画面は変更しません。再生時に反映し、編集時は `HimoHito > Preview > Refresh Scene Visuals` でも更新できます。

本編／チュートリアルでヒモの先端がフックに届くと、接続点に小さな毛糸の結び目が約0.2秒でできて締まります。既存のヒモと同じ透過素材を使い、リングの縁は隠しません。接続中は静止し、Eなどの手動解除で約0.12秒かけてほどけながら、既存の「頭へ戻るヒモ」の先端へつながります。届く前の解除では結び目を出さず、途中解除は途中の形を引き継ぎます。Q足場化・失敗・再挑戦では結び目を消し、ポーズ中は停止。接続／解除の判定・速度・ヒモ消費・既存の戻り時間0.38秒は変えず、音・光・カメラ揺れは追加しません。

チュートリアルでは、現在区間の看板に読む範囲まで近づくと、看板の絵だけが支柱の根元を軸に小さく傾き、約0.85秒で戻ります。結び目から垂れた毛糸の先端は少し遅れて揺れます。近くに居続けても繰り返さず、読む範囲より0.85ユニット以上離れて戻ると再び反応します。看板・Tab説明・ポーズ中は動きを止め、失敗／開始前／見渡し中には新しく反応しません。Zキー、読む範囲、看板本体の位置は変えず、音・コライダー・カメラ揺れは追加しません。

落下で失敗が確定すると、頭側から編み目がほどけ、同じ毛糸素材の6本の短いヒモへ変わる演出を約0.8秒表示してから失敗画面へ移ります。落下時の姿と位置をそのまま使い、演出のために画面内へ引き戻しません。画面外で失敗した場合、ほどける演出も画面外で進みます。主人公本体・カメラ・落下判定位置は動かしません。演出中は操作を止め、終了後はRで再挑戦／Escでステージ選択に戻るまで失敗画面を維持します。再挑戦では元の描画を戻し、0.8秒の編み戻りへつなぎます。ヒモ切れの失敗ではこの落下演出を再生せず、追加の音・フラッシュ・カメラ揺れはありません。

本編／チュートリアルで区間から再挑戦すると、主人公が約0.8秒で足→胴体→頭の順に編み戻ります。既存のキャラクター画像を横の編み目ごとに表示し、左右から短い毛糸が集まります。初回開始・通常の区間到達では再生せず、Rによる再挑戦で確認できます。演出中も移動・ジャンプ・接続は可能で、カメラ・復帰位置・ヒモ残量には干渉しません。ポーズ中は止まり、失敗・クリアなどで操作が止まった場合は元の描画へ戻します。発光・追加の音はありません。

着地と地上ジャンプの踏み切りには、ヒモと同じ透過テクスチャの短い毛糸繊維が足元で散ります。通常着地・踏み切りは3本、落下速度8以上の強い着地だけ5本。約0.4〜0.65秒で消え、煙・発光・追加の音・カメラ揺れはありません。空中時間0.08秒未満の接地揺れでは着地の粒を出さず、空中の猶予ジャンプでは踏み切りの粒を出しません。着地直後の先行入力ジャンプは踏み切りだけにまとめます。繊維には当たり判定がなく、プレイヤー移動後も発生位置に残り、ポーズ中は停止します。

ヒモの先端がフックへ届くと、その瞬間のプレイヤーの頭頂方向へリングの絵だけが少し引かれ、傾いて戻ります。青／緑フック共通で約0.42秒、移動は最大0.06ユニット、膨らみは最大4％。従来の上下に跳ねる膨張演出を置き換え、連続振動・発光・追加の音はありません。ポーズ中は停止。接続点・フック本体・当たり判定・ヒモの長さや物理は固定のままです。

- ヒモを掛けて振り子移動するだけでは残量を消費しない
- 接続中に`E`を押すと、勢いを保ったままヒモを外す
- 接続中に`Q`を押した時だけ、選んだ長さを永久に消費して足場を作る
- Qで作ったヒモ橋は、プレイヤーに近い端から約0.3秒で毛糸が編み上がる。完成前の部分も薄く表示し、足場判定は生成直後から有効。ポーズ中は演出も停止する。F統合やリトライ復元では再生しない。
- Qで足場生成に成功した瞬間は、橋に沿って6〜12個の小さな毛糸片が舞い、約1秒以内に消える。見た目だけの粒子で、衝突判定はない
- Qで足場生成に成功すると、残量の数字とゲージ本体は即時更新し、消費分だけ薄いピンクの残像として約0.4秒で縮める。結び目も元の位置から新しい残量位置へ滑らかに移動し、右側へ「−7」などの実消費量を約0.95秒表示する。短時間の連続生成は残像の途中からつなぎ、消費表示を合計する。従来の白いフラッシュは撤去。接続・解除、生成失敗、Fでの統合、残量復元では新しく発生せず、再挑戦・復元では残像を消す。ポーズ中は時間を進めず、本編50／チュートリアル99共通。HUDの高さは変えず、ゲージ右に固定の数字用余白を確保する。物理・実消費・音・カメラは不変更。
- 着地音が鳴る着地では、空中に0.08秒以上いた場合に足元から5片の小さな毛糸が舞い、0.4〜0.6秒で消える。ヒモと同じ模様を使い、衝突や力の作用はない。歩行用の演出は追加しない。
- 足場用Hookでは、選んだ長さが対になった2つのHook間の実距離以上なら足場を作れる。資料の長さは攻略時の推奨値で、長くした分は消費とたわみが増える
- 足場は選んだ長さと両端の直線距離との差だけ下へたわむ
- 2本の足場が同じHookへ集まっている時、Hookへ照準を合わせて`F`を押すと、Hookを外して1本の足場へまとめる
- F統合時は、2本の橋の見た目が約0.4秒で1本のたわんだ形へ下がる。統合後の足場位置を薄く重ね、物理判定は従来どおり即時に統合する。ポーズ中は演出も停止する。

- 残量は最低1以上残す必要がある
- 落下時は失敗画面で待機し、`R`で現在の区間から再開する。プレイ中の`R`でも再挑戦できる
- チェックポイント到達時の残量が次区間の最低必要量を下回る場合だけ、指定された下限まで補充する

振り子移動では`DistanceJoint2D`を使います。接続中の入力はHookを中心とする円の接線方向へ力を加え、解除時は速度を保存します。
接続成功時は主人公からHookへ約0.13秒でヒモが伸び、先端が届いた時に既存の接続音とリングの小さな揺れを出します。青・緑のリングは約0.28秒で最大14％膨らみ、元の大きさへ柔らかく戻ります。演出だけの遅延で、接続判定・ジョイント・振り子操作は従来どおり即時に有効です。途中で解除・足場化した場合は未再生の接続音を取り消します。リングの揺れと拡縮は描画用の子だけに適用し、Hookの座標や当たり判定は動かしません。
プレイヤーから伸びる接続中のヒモと生成したヒモ橋には、主人公の頭の毛糸を参考にした同じピンクの撚り模様を使います。背景を読み込み時に除去し、模様を長さ方向に繰り返すことで引き伸ばしを防ぎます。Fで統合した橋にも同じ模様を適用します。照準線は従来のデザインのままです。残量に応じた接続ヒモの線幅、橋の太さ、たわみ形状、当たり判定は変えていません。
生成したヒモ橋は見た目の形を変えずに40点以上の連続した当たり判定で構成しています。プレイヤーの判定サイズと通常床を含む接地摩擦は従来の値を維持しながら、上り坂でヒモ橋の折れ目へ引っ掛かりにくくしています。入力なしでヒモ橋に立っている間は、摩擦を消さずに重力の斜面方向成分だけを相殺し、たわみの底へずるずる滑らないようにしています。
接続した直後にヒモがたるんでいる場合や、下Hookがプレイヤーより低い場合も、`A`/`D`の入力を左右へ進む接線方向の力へ変換して床の端から動き出せます。プレイヤーがHookより下へ回り、ヒモが張ると通常の振り子入力へ切り替わります。
下Hookへの接続直後は、接線の横成分が小さい角度でも床の摩擦に負けない起動力を加えます。力の向きはHookを中心とする円の接線のままなので、振り子の物理制約は変えません。
ヒモを接続できるのは青または緑の専用Hookだけです。床・壁・梁・生成済み足場・空中そのものは接続先にならないため、地形の角へ誤接続しません。第6区間では、青Hookから解除した直後に限り、空中から次の連続青Hookへ再接続できます。

## チュートリアル — 4区間

1. **掛けて、振って、渡る**：下まで続く2つの地形を置き、中央上のHookへ掛ける。初期選択長は6だが、T1から`W/S`で変更でき、矢印キーで照準方向も選べる。プレイヤーの開始位置は床上面と当たり判定の高さから算出し、わずかに接地側へ入れて空中開始を防ぐ。長さ6なら掛けた瞬間は床に立ったままで、歩き出した時に振り子になる。着地床は従来位置から右へ4広げ、長さ9前後を選ぶことで到達できる。着地時はヒモを強制解除せず、接続状態と勢いを保ったままT2へ進む。`Q`はまだ教えない。旧チュートリアル由来のHook・床・ゴール・懐中電灯ギミックはシーンから削除し、落下時は失敗画面で入力を待ち、`R`で現在区間のチェックポイントへ戻る。ヒモは減らない
2. **長さを選ぶ**：T1の着地床を左岸として対岸と中央Hookを置く。対岸の中心はX=`27`で、旧位置から右へ3移動している。初期長さ8ではプレイヤーの足元が木製トゲへ約0.72入り、長さ7では約0.28上を通り、長さ6でも振り幅を作れば対岸へ届く。T1から接続を保って入った場合は`E`で外し、`W/S`で6または7へ選び直して渡る。対岸の上面へ着地した時だけT3の復帰地点を記録し、壁側面への接触では更新しない。失敗してもヒモは消費しない
3. **ヒモを足場にする**：T2右岸の右端X=`30`と新しい右岸の左端X=`36`を使い、頭上に振り子用Hookがない谷幅6を作る。両岸の内側端には本編と同じ緑色の足場用フックを置く。谷の手前から対岸の緑フックへ長さ6で`E`接続し、`Q`で2つの緑フック間を直線に近い足場で結ぶ。岸端に立つプレイヤー中心と固定点のずれは、全足場用Hook共通の照準補助0.5で吸収する。チュートリアル開始残量99から6を永久消費して93になり、右岸上面へ着地した時だけT4の復帰地点を記録する
4. **Hookを外してまとめる**：資料T5を、本編に対応する内容がない旧T4の代わりに最終区間として繰り上げる。T3右岸の右端X=`42`から中央Hook、右岸の左端X=`52`までを、長さ6の足場2本で結ぶ。通しプレイでは残量93から12を消費して81になる。左側の足場を作った後は、中央Hookを`E`の接続候補から外して右の緑Hookを狙えるようにする。中央Hookは`F`の対象として残る。2本のままでは吊り梁に当たるが、中央の青Hookへ照準を合わせて`F`で外すと、両端距離10・総長12・たわみ2の1本になり、梁の下を通ってゴールできる

区間1から`W`/`S`と矢印照準を使用し、区間3から`Q`、区間4で`F`を使用します。
各区間の開始床には、三枚板と一本脚にピンクのヒモを結んだ木製の看板があります。看板の近くで`Z`を押すと、現在の区間だけに必要な操作と正解例をイラスト付きで確認できます。説明中は物理と操作を一時停止し、もう一度`Z`を押すと同じ状態から再開します。

- 本編の通常床・壁床・着地床は、チュートリアルと同じ蜂蜜色の木製ブロック素材を使う。ワールド単位のUVで模様の密度を保ち、広い床・細い柱・薄棚でも引き伸ばさない。青いレール床、ピンクのヒモ足場、赤いトゲは機能を見分けられる現在の色と形を維持する
- ステージに最初から置かれた床・棚・梁・壁は、振り子中も上下左右から衝突する
- 青いHookは横棒付きの振り子用、緑のHookは中央の輪だけを残した2点式の足場作成用として見分ける。どちらも接続判定だけを持つ固定点として扱い、未接続時も振り子中もプレイヤーの移動を物理的に遮らない
- フックの接続用トリガーは接地判定から除外する。床からヒモ橋へ歩くときは、橋の厚みによる小さな段差だけを上へ補正する（通常約0.13、上限0.18）。橋の半径も含めて手前で検出し、衝突後の押し直しを不要にする。地上歩行中・床と同じ高さの橋の入口に限定し、静止・ジャンプ・空中・接続中・頭上に障害物がある場合は補正しない。橋上では実際の足元の接触面に沿って歩き、中央フックで足がまだ平らな頂点にある間は下り坂へ押し込まない。接触が途切れた瞬間は速度を先の橋の傾きへ上書きせず、通常の空中制御を使う。フック座標、橋の形・太さ、摩擦、ジャンプ力、振り子の力とヒモ残量計算は変更しない
- ヒモの接続先は青または緑の専用Hookだけとし、床・壁・梁・生成したヒモ足場・空中そのものには接続できない
- プレイヤーが空中にいること自体は禁止条件ではない。第6区間の青Hook連続ルートでは、解除後1.5秒以内に次の青Hookへ再接続できる
- 生成したヒモ足場は通常時に歩ける。歩行中は足元の局所的な傾斜に沿って地上速度を補正し、たわみの底を越えた時の慣性で橋から浮かないようにする。上り坂で接触点がColliderの端へ移っても、橋が実際に足元を支えている間は接地を維持する。足場作成用Hookへ`E`で接続した時は振り子へ移行せず、その位置を`Q`で足場化するか`E`で解除するまで保持する。接続中はすべての生成済み足場との衝突も維持する。振り子用Hookへヒモ足場の上から接続した場合は、足場を離れるまで衝突を維持し、離れた後は無効にして振り子軌道を妨げない
- 赤い木製玩具の三角トゲや懐中電灯へ接続中のプレイヤーが触れると、ヒモが外れて落下する

## ヒモ残量の見せ方

通常プレイの左上HUDは、区間・残量と木製ゲージ・次に使う長さ（接続中表示）・Tab案内に絞る。操作一覧と常時攻略文、速度表示は省き、詳しい操作はTab、チュートリアルの区間説明はZの看板で確認する。

残量は数字とゲージで表示します。見た目の身体は残量に応じて4段階に小さくなりますが、Rigidbody2DとCollider2Dの大きさは変えません。操作性を変えずに「自分の身体を使っている」ことだけを伝えるためです。

## Unity Editorでの実行

1. Unity Hubでこのフォルダをプロジェクトとして追加する
2. Unity `6000.3.21f1`で開く
3. `Assets/Scenes/Tutorial.unity`を開く
4. Playを押す

起動時は布製マップのステージ選択を直接表示します。旧タイトルを挟まず、`Enter`で選んだステージを開始し、`Tab`で操作説明、`Esc`で終了します。ポーズ・失敗・クリア画面からもこの選択画面へ戻ります。チュートリアルクリア後は`Enter`で本編へ進みます。
操作説明は同じ子供部屋の画風で描いた白紙の工作用紙へUnity側で操作表を重ね、ゲーム中に開いた場合は閉じるまで進行を一時停止します。
失敗・クリア演出・クリア画面では通常プレイ用の操作案内とTab／Escのポーズ処理を止め、各結果画面の操作を優先します。看板や操作説明、ポーズの表示中も通常の右上案内は重ねません。
子供部屋の遠景はカメラ移動の98.5%、透過した棚・玩具の中景は93%で追従し、奥ほど画面上の動きを小さくしています。各3枚の背景を左右反転して再利用し、画面比率・高さに合わせて縦横比を保って拡大。長い本編、紹介カメラ、再挑戦、第10区間の高さ変化でも背景が途切れない構成です。編集画面では `HimoHito > Preview > Refresh Scene Visuals` で更新できます。元の背景素材は残しています。
本編とチュートリアルのクリア画面には、細くなった主人公がおもちゃ箱へ帰る共通のエンディング背景と、「あなたが残した道」の小さな見取り図を表示します。実際の床・レール、クリア時に残ったヒモ橋、STARTと宝箱を描き、残量と現在の橋の本数を添えます。Fでまとめた橋は1本で表示します。全移動軌跡や累計生成回数ではなく、そのクリア時点の記録です。本編では補充回数・クリア時間も表示します。長いステージを収めるため縦横の縮尺は独立した簡略図とし、画面比率に合わせて全体を縮小します。チュートリアルのEnterで本編へ進む操作、本編のRで再挑戦する操作と、クリア画面へ移るタイミングは従来どおりです。
両方のクリア画面では、下部に「本編ステージへ／本編を最初から再挑戦」と「Esc ステージ選択へ戻る」の木製ボタンを横並びで表示し、クリックでも操作できます。Escで戻る際は音量設定を保持して時間倍率を通常へ戻し、ステージ選択を新しく読み込みます。戻ったフレームのEscをゲーム終了として再利用しません。クリア演出の1.35秒中はこの操作を受け付けず、操作するまで結果画面を維持します。

ヒモが尽きた時と落下した時は、床に残った短いヒモと遠いおもちゃ箱を描いた共通の失敗画面を表示します。画面は自動で切り替わらず、`R`で現在区間から再挑戦し、`Esc`でステージ選択へ戻れます。

再挑戦では物理座標と表示座標を同時に復帰先へ戻し、落下判定には物理座標を使用します。補間表示に残った前回の落下位置で再び失敗しないようにし、0.8秒の編み戻り演出は維持します。
Play時は`Tutorial.unity`のT1先頭から、残量99・選択長6・生成済み足場なしで開始します。最初からやり直した場合も同じ状態へ戻ります。チュートリアルをクリアすると本編へ進みます。

本編は`MainStage.unity`の第1区間から、残量50・選択長7・生成済み足場なしで開始します。落下時と`R`での再挑戦も、到達済みの現在区間のチェックポイントへ戻ります。

第1区間のゴール床（Main Landing 1）に安定して着地し、ヒモを解除すると第2区間の復帰地点(9.5, -4.15)を保存します。壁や角への接触だけでは更新しません。本編の床・フック・危険物のセットアップは、直接起動だけでなくチュートリアルからの遷移と本編再ロードでも実行します。トゲ・光の判定・木製トゲの表示は個別のスクリプトとGUIDで保存し、同じ光の判定を重複して追加しません。

Windows配布版はZIPを展開し、ルートにある`START_HIMOHITO.bat`から起動します。Unity 6.3の第2シーン読み込みが日本語を含む実行パスで停止する環境があるため、ランチャーがゲーム本体を`C:\Users\Public\HimoHitoPrototype`へコピーしてから起動します。`Game`フォルダ内のexeは直接起動しないでください。配布版は全画面で開始し、`Alt + Enter`でウィンドウ表示と切り替えられます。

## Windows版を作成

1. Unity上部メニューの`HimoHito > Build Windows Prototype`を押す

ビルド直前に第7回資料の提出用設定を自動適用します。
